# CalDock 实施与验收

目标：原生、紧凑、低资源的 macOS 菜单栏日历，参考提供的四张软件截图。

## 实施阶段

1. 已完成日历核心：月网格、农历、节日、节气、官方调休数据、日期格式；14 项核心回归测试通过。
2. 已完成原生菜单栏与面板：模板图标、当前全屏空间、快捷键、月历与日程；已实测月切换、深浅主题、固定、日程未授权提示和全屏呼出。
3. 已完成设置：通用、事件、样式、状态栏、关于；持久化、事件授权、节日通知和软件更新；已实测模块开关、排序、颜色模式与五页导航。
4. 已完成 WidgetKit 小/中/大月历、独立配色及显示设置、共享容器、系统午夜时间线；用户已确认编辑器中可搜索并看到预览。
5. 交付：Universal release 应用、Developer ID 签名、/Applications 安装、应用内及真实系统验收、资源占用取样、使用和构建说明。

## 约束

- macOS 14+，Swift/AppKit/SwiftUI，更新使用 Sparkle；不引入额外常驻服务或 WebView。
- 事件仅在授权后按可见日期范围读取，使用 EventKit 变更通知刷新。
- 默认分钟级定时器，只有启用时间秒数才每秒更新；收起面板停止日历视图工作。
- 法定休息和补班必须来自已核实的年度通知，未收录年份不推算调休。
- 全屏辅助窗口支持当前空间；系统隐藏菜单栏或刘海区挤压不等于图标配色问题，保留全局快捷键入口。
- 通知中心/桌面 Widget 使用真实 WidgetKit 扩展，无轮询服务。

### 2026-10-17 · 日程快速添加

- 展开日程后，标题栏右侧增加紧凑 `＋` 按钮；Popover 仅保留事件／提醒类型、标题、日期或时间及可写入的日历／提醒列表，不改变月历主体尺寸。
